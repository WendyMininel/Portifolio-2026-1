# Portfólio Acadêmico e Profissional — 2026/1

Portfólio pessoal desenvolvido para apresentar minha trajetória acadêmica, habilidades, projetos, cursos e certificações nas áreas de **Análise e Desenvolvimento de Sistemas** e **Biomedicina**.

O projeto foi construído utilizando **HTML5, CSS3 e JavaScript**, com foco em organização de informações, interatividade, responsividade e experiência do usuário.

## Acesse o Portfólio

**[Visualizar Portfólio Online](https://portifolio-2026-rho.vercel.app/)**

## Sobre o Projeto

O portfólio foi desenvolvido com o objetivo de reunir, em uma única plataforma, informações sobre minha formação acadêmica, experiências, competências e projetos desenvolvidos ao longo da graduação.

A aplicação apresenta uma interface interativa que permite alternar entre dois perfis acadêmicos: Tecnologia e Biomedicina.

Cada perfil apresenta informações específicas, proporcionando uma navegação personalizada de acordo com a área de interesse do visitante.

O projeto também permite explorar trabalhos acadêmicos, consultar certificações e acessar canais de contato profissional.

## Funcionalidades

- Alternância dinâmica entre os perfis de Tecnologia e Biomedicina.
- Apresentação de informações pessoais e acadêmicas.
- Exibição de formações acadêmicas específicas para cada área.
- Organização de habilidades técnicas, comportamentais e idiomas.
- Apresentação de projetos acadêmicos e suas tecnologias.
- Pesquisa de projetos por nome, descrição ou tecnologia.
- Listagem de cursos e certificações.
- Filtros de cursos e certificações por categoria.
- Pesquisa de cursos por palavras-chave.
- Acesso a certificados em formato PDF.
- Links para redes sociais, GitHub, LinkedIn e currículos.
- Saudação dinâmica de acordo com o horário do visitante.
- Alteração de informações e imagens conforme o perfil selecionado.
- Layout responsivo para diferentes tamanhos de tela.

## Organização dos Arquivos

### index.html

Responsável pela estrutura principal da página, incluindo as seções de apresentação, formação acadêmica, habilidades, projetos, cursos, certificações e contato.

### styles.css

Contém as regras de estilização do portfólio, incluindo cores, tipografia, espaçamentos, componentes visuais, efeitos de interação e adaptações para diferentes tamanhos de tela.

### script.js

Responsável pelas funcionalidades interativas da aplicação, como:

- Alternância entre os perfis acadêmicos.
- Renderização dinâmica de informações.
- Pesquisa e filtragem de projetos.
- Pesquisa e categorização de cursos e certificações.
- Atualização dos links profissionais.
- Alteração das imagens e dos conteúdos conforme o perfil selecionado.
- Exibição de saudações dinâmicas.

### img/

Diretório destinado ao armazenamento de imagens utilizadas na apresentação visual do portfólio.

### pdfs/

Diretório utilizado para armazenar documentos acadêmicos e profissionais, incluindo certificados de cursos, participações em eventos e currículos.

## Como Executar

**1.** Clone o repositório:

```bash
git clone https://github.com/WendyMininel/Portifolio-2026-1.git
```

**2.** Acesse a pasta do projeto:

```bash
cd Portifolio-2026-1/portifolio2
```

**3.** Abra o arquivo `index.html` em um navegador.

Também é possível utilizar a extensão **Live Server** do Visual Studio Code para executar o projeto localmente.

A aplicação não necessita de instalação de dependências ou configuração de backend.

## Responsividade

O portfólio utiliza recursos de CSS, como Flexbox, Grid Layout e Media Queries, para adaptar a interface a diferentes dispositivos.

A estrutura contempla ajustes para computadores, tablets e smartphones, reorganizando elementos de navegação, cartões e conteúdos conforme a resolução da tela.

## Objetivo

Desenvolver uma plataforma pessoal capaz de apresentar minha trajetória acadêmica e profissional de maneira organizada, acessível e interativa.

O projeto também tem como finalidade aplicar conhecimentos de desenvolvimento frontend, manipulação do DOM, responsividade, estilização de interfaces e organização de informações.

Além disso, o portfólio funciona como uma ferramenta de apresentação profissional, reunindo projetos e qualificações que demonstram minha evolução nas áreas de Tecnologia e Biomedicina.
